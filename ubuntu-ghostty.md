# Moving from WSL2 to Ubuntu + Ghostty

I previously used Claude Code in WSL2 with Windows Terminal. I now use Ubuntu
with Ghostty, which already meets my day-to-day terminal needs.

Much of this repository connected the Windows desktop to tools inside WSL:
[screenshot paste](image-paste.md), [Windows notifications](claude-notify.md),
and [opening links in the Windows browser](browser.md). I no longer need that
Windows/WSL integration in my own workflow.

[LSP navigation](lsp-setup.md) and the [statusline](statusline.md) address separate
needs; Ghostty does not replace those Claude Code features.

There is no Ubuntu edition planned because I do not currently have another set
of workarounds to package. The [WSL2 guides](README.md) remain available for people
who need Windows. I no longer test them daily, and fixes tested on WSL2 are welcome.
