# Frontend Design

Build real UI with taste. Choose a deliberate aesthetic direction, then implement it cleanly instead of defaulting to generic AI-looking layouts.

## Workflow

1. Identify the product context, audience, constraints, and the one memorable quality the interface should have.
2. Pick a strong visual direction before writing code.
3. Implement working code that matches that direction consistently across layout, typography, color, motion, and states.
4. Preserve an existing design system if the repo already has one. Otherwise, create a clear visual system with CSS variables or theme tokens.

## Design Rules

- Avoid generic font stacks, purple-on-white defaults, and interchangeable dashboard patterns.
- Treat typography, spacing, and composition as first-class decisions.
- Use motion intentionally. Prefer a few strong moments over constant micro-animation.
- Make the page work on both mobile and desktop.
- For React code, follow the repo's existing patterns before introducing abstractions.

## Output

Ship code, not just design language. Explain the chosen aesthetic briefly if it helps the user understand the implementation.
